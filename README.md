# Todo List API با Flask و SQL Server

## توضیحات پروژه
یک API ساده برای مدیریت لیست کارها با قابلیت‌های:
- ایجاد تسک جدید
- مشاهده تمام تسک‌ها
- آپدیت و حذف تسک‌ها

## راه‌اندازی
1. نصب کتابخانه‌ها:
   ```bash
   pip install flask flask-sqlalchemy pyodbc

## ویژگی‌ها

- **احراز هویت** با استفاده از **JWT (JSON Web Tokens)**
- **صفحه‌بندی (Pagination)** لیست تسک‌ها
- **اعتبارسنجی داده‌ها** (مثل طول توضیحات تسک)
- **مدیریت خطاهای پیشرفته** برای درخواست‌های نامعتبر
- **قابلیت مرتب‌سازی و فیلتر کردن تسک‌ها** بر اساس تاریخ یا وضعیت
- **ذخیره‌سازی اطلاعات در پایگاه داده SQL Server**
- **API RESTful** با استفاده از Flask

### پیش‌نیازها

- **Python 3.x**
- **SQL Server** یا هر پایگاه داده‌ی رابطه‌ای دیگر
- **pip** برای نصب پکیج‌ها
